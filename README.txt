唐宋元明清 · 历史站（离线单页版）
========================================

打开方式
  电脑：双击 index.html，浏览器直接打开（离线可用，无任何外部请求）。
  手机：把「唐宋元明清-手机版.html」传到手机，双击用浏览器打开。
        该文件已把全部数据内联（约 10.1 MB），不联网也能看。

目录结构
  index.html                主页面（单页应用）
  pkg/                      数据包（按朝代分成本纪 / 人物两类）
  README.txt                本说明
  验收.txt                  本轮验收记录与数据缺口清单
  唐宋元明清-手机版.html     单文件手机版（数据全内联）

  「新规范」= 每卡写「前因（结构条件／近端触发／决策者动机）— 经过 — 后果」，
  带因果链、为什么问答、转折点，每个皇帝 4–6 个主线节点；
  末卡的「因此」接向下一位皇帝的首卡。
  「旧短卡」= 原五朝站的条目式短摘要，仍可正常点开阅读，只是没有因果长卡。

引文说明
  本轮所有引文逐字取自库内白话底本（《明朝那些事儿》等），
  页面标注「白话著作，非正史原文」。没有编造《明史》《宋史》《元史》
  《清史稿》《旧唐书》《新唐书》的卷次，也没有伪造正史原文；
  书内无记载处标「史无明文」。

朝代切换与缺包提示
  顶部朝代条可切换唐、宋、元、明、清。若某朝数据包缺失或不可读，
  页面会显示「暂未收录」提示与补包方法，不会白屏或空画布。

补数据包
  1) 把 <朝代>-benji.js 与 <朝代>-people.js 放进 pkg/；
  2) 在 index.html 的 DYN 数组中登记该朝代；
  3) 新规范长卡数据放在 pkg/mr-<朝代>-b.js / mr-<朝代>-p.js，
     并在 index.html 末尾按顺序引入。
