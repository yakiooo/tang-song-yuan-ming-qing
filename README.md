# 唐宋元明清 · 五朝历史图谱

一个纯前端的五朝历史交互站：世代顺位图 + 皇帝本纪 + 人物长卡 + 朝代时间轴 + 专题年谱。双击 `index.html` 即可打开，无需联网、无需服务器。

## 操作

- 顶部朝代条切换唐/宋/元/明/清，或进「时间轴」看跨朝事件
- 世代顺位图点卡片进入本纪/人物页，正文人名可点继续跳转
- 右侧导轨：返回键回上一级；目录点选跳板块；「上一块/下一块」逐段翻页；边缘箭头可收起
- 左侧进度条：点轨道按比例跳到对应板块
- 顶部有检索、人物排行、总目、专题、解析统计
